## 👋Introdcuton
This is a very used and needed model, which detects if an email is spam or ham(not spam). The model we have used here is **LogisticRegression** and it is good when they are only 2 classes. <br>
The current accuracy rate is from **94%-96%**.

---

## 📊Dataset
We have used an dataset called spam_email.csv, which conists of around 5000+ sample datasets, it is small in size but has yeilded good accuracy. <br>
You can download the data set by running: <br>
```bash
curl -L -o main/mail_data.csv https://drive.google.com/file/d/1DNd9pArBy88YPDRKj04M7IzuWEZMqqWN/view?usp=drive_link
```
